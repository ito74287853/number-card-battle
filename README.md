# 数字カードバトル

配られた数字カードの合計で敵のHPを超えたら勝ち。勝つたびにカードを1枚デッキに加えて、5ラウンドの制覇を目指すブラウザ向けミニゲームです。

## 遊び方

```bash
npm install
npm run dev
```

表示されたURLをブラウザで開き、タイトル画面でキー入力かタップでスタートします。

1. 手札からカードをタップで選ぶ（複数選択可）
2. 「勝負」で合計と敵HPを比較。合計が敵HP以上なら勝利
3. 勝利後、報酬カード3枚から1枚を選んでデッキに追加（スキップも可能）
4. 5ラウンド勝ち抜けばクリア。負けたら最初から

### 累積超過（バースト）ルール

勝った試合の「超過分」（合計−敵HP）はラン中ずっと積み上がっていきます。この累積超過が上限（デフォルト20）を超えると、たとえ勝った試合でも「使いすぎで自滅」として負け扱いになります。手札を全部使うのが常に正解とは限らないので、ギリギリ勝てる枚数だけを選ぶ判断が重要です。

## 技術構成

- [Vite](https://vitejs.dev/) + 素のJavaScript（Canvas 2D）
- `src/core` : ゲームループ・シーン管理
- `src/scenes` : タイトル・戦闘・報酬画面
- `src/entities` : カードの見た目
- `src/utils` : デッキ生成・当たり判定
